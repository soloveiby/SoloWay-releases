# SoloWeek — сборки

Расписание для студентов (бета). Здесь только готовые APK, код — в отдельном репозитории.

**Установить:** открой [последний релиз](https://github.com/soloveiby/SoloWeek-releases/releases/latest) и скачай `SoloWeek-NN.apk`.
Android спросит разрешение на установку из браузера — это нормально для приложений не из Google Play.

**Обновления** приходят сами: приложение раз в несколько часов проверяет этот репозиторий и предлагает установить новую версию.
